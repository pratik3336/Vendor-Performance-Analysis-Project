## 📊 Vendor Performance Analysis Project

An end-to-end **data analytics case study** designed to demonstrate real-world business analysis using **SQL, Python, and Power BI**. This project simulates a production-level vendor performance evaluation workflow — from raw procurement data processing to actionable business insights and dashboard reporting.

---

## 🚀 Project Overview

This project focuses on analyzing vendor procurement data to evaluate performance, identify inefficiencies, and support data-driven business decisions.
It covers the complete analytics lifecycle including data cleaning, exploratory analysis, visualization, and business reporting.

## 🔧 Key Components

### 📥 Data Processing & Preparation

* Handling raw and cleaned procurement datasets
* Data wrangling using SQL and Python

### 🐍 Exploratory Data Analysis (Python)

* Pattern discovery and trend analysis
* Statistical evaluation (confidence intervals, hypothesis testing)
* Business question exploration through notebooks

### 🗄 SQL-Based Analysis

* Querying large procurement datasets
* Vendor performance metrics calculation
* Aggregations, joins, and optimization techniques

### 📊 Power BI Dashboard

* Interactive visualization of vendor KPIs
* Performance comparisons and trend insights
